# Security Policy - Password-Generator-Advanced

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in **Password-Generator-Advanced**, please report it responsibly:

1. **Email**: [valorisa@users.noreply.github.com](mailto:valorisa@users.noreply.github.com)
2. **Do NOT** open a public issue for security vulnerabilities
3. Include steps to reproduce the vulnerability
4. We will acknowledge receipt within 48 hours
5. A fix will be released as soon as possible

## Disclosure Policy

- We follow coordinated disclosure
- Security patches are released as soon as a fix is available
- CVEs are requested when applicable
